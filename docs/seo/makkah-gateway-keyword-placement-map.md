# Keyword Placement Map

This map outlines the planned placement of primary and secondary keywords for the 23 target pages.

## Placement Strategy
* **Primary Keyword**: Placed exactly in the SEO Title, `<h1 class="h2">` (breadcrumb header), and naturally inside the first 100 words of the introductory copy.
* **Secondary Keywords**: Distributed naturally across `<h2>`/`<h3>` subheadings, introductory body copy, customized FAQs, and image alt texts.
